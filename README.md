🛒 BazarDor (বাজার দর)

Your Smart Marketplace for Everyday Shopping

📌 Project Description

BazarDor is a modern web application designed to make online shopping easier and more convenient. It provides users with a user-friendly platform to explore products, view product details, and manage their shopping experience.

🛠️ Technologies Used

Next.js — React framework for building web applications

React.js — Component-based user interface development

TypeScript — Type-safe JavaScript development

Tailwind CSS — Responsive and modern UI styling

Git & GitHub — Version control and project collaboration

✨ Key Features

Product Browsing — Explore available products through a clean and organized interface.

Product Details — View product information, descriptions, and prices.

Responsive Design — Enjoy a consistent experience across desktop, tablet, and mobile devices.

Modern User Interface — Navigate easily with a clean and intuitive design.

Type-Safe Development — Use TypeScript to improve code reliability and maintainability.
